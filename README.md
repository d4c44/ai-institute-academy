# AI Institute Academy · Korkyt Ata Kyzylorda University

Платформа онлайн-курсов по искусственному интеллекту с проверяемыми сертификатами.

| Часть | Технологии |
|---|---|
| Фронтенд (`/`) | Next.js 16 (App Router, Cache Components) · Tailwind 4 · shadcn/ui · next-intl (kk / ru / en / ko) |
| Бэкенд (`backend/`) | Go 1.27 · `net/http` · pgx · goose (миграции) |
| База данных | PostgreSQL 18 (сервер) |

Браузер всегда обращается к Next.js; запросы `/api/v1/*` Next.js проксирует в Go API, поэтому cookie сессии работают без CORS.

## Быстрый старт

Нужны Node.js 22+, Go 1.27+ и PostgreSQL 18.

**1. База данных (один раз).** На Windows: впишите пароль в `backend/.env` (`DATABASE_URL`, образец в `backend/.env.example`) и выполните `& .\backend\db\setup-local.ps1`, скрипт спросит пароль суперпользователя `postgres`. На других системах от имени суперпользователя:

```bash
psql -U postgres -h localhost -v app_password='ВАШ_ПАРОЛЬ' -f backend/db/init.sql
```

**2. Бэкенд:**

```bash
cd backend
cp .env.example .env        # впишите тот же пароль в DATABASE_URL
go run ./cmd/api migrate    # применить миграции
go run ./cmd/seed           # пример курса на четырёх языках (необязательно)
go run ./cmd/api            # http://localhost:8080
```

**3. Фронтенд** (в корне репозитория):

```bash
npm install
cp .env.example .env        # API_URL указывает на Go API
npm run dev                 # http://localhost:3000
```

## Сайт на GitHub Pages

https://d4c44.github.io/ai-institute-academy/ — статическая версия сайта (`npm run build:static`, публикует `.github/workflows/pages.yml`). Сервера за ней нет: в браузере посетителя работает копия API (`src/static/backend.ts`), а аккаунты, прогресс и сертификаты лежат в localStorage этого браузера и не уходят никуда. Поэтому PDF-сертификата нет (кнопка открывает страницу сертификата и печать), а данные не переносятся между устройствами. Настоящий стек с Go и PostgreSQL запускается как описано ниже.

Тексты курсов для неё берутся из Go-сида (`npm run static:content`, CI следит, чтобы файл не отставал).

## Открыть настоящий сайт через GitHub (Codespaces)

Codespaces запускает весь стек, а не копию: облачная среда сама поднимает PostgreSQL, Go API и сайт (`.devcontainer/`). Откройте https://codespaces.new/d4c44/ai-institute-academy?quickstart=1, нажмите «Create codespace», подождите 5–8 минут (первая сборка) и откройте вкладку Ports → строка Site. Адрес доступен только вам, пока вы вошли в GitHub. Среда засыпает через 30 минут простоя, при следующем запуске сайт поднимается сам, данные в базе сохраняются. Бесплатный лимит личного аккаунта: 120 ядро-часов в месяц.

GitHub Actions собирает образы и обновляет свой сервер по SSH; настройка с нуля описана в [docs/DEPLOY.md](docs/DEPLOY.md).

## Через Docker

```bash
docker compose up -d --build   # PostgreSQL + миграции + API + сайт на :3000
```

Перед использованием на реальном сервере задайте `POSTGRES_PASSWORD` и `APP_URL` в `.env` рядом с `docker-compose.yml`. Чтобы использовать свой сервер PostgreSQL, уберите сервис `db` и укажите `DATABASE_URL` для `migrate` и `api`.

## Структура

```
messages/                  переводы интерфейса: kk.json, ru.json, en.json, ko.json (en — эталон для типов)
src/app/[locale]/          страницы; (public)/ — публичная часть
src/components/            ui/ (shadcn), site/ (шапка, подвал), home/, course/
src/i18n/                  маршрутизация языков, конфиг next-intl
src/lib/api/               клиент Go API (серверный код)
src/proxy.ts               выбор языка (бывший middleware.ts)

backend/cmd/api/           HTTP-сервер и `migrate`
backend/cmd/seed/          демо-данные (идемпотентно)
backend/internal/httpapi/  маршруты и middleware
backend/internal/store/    запросы к PostgreSQL
backend/migrations/        SQL-миграции (встраиваются в бинарник)
```

## Обучение и сертификаты

Пример курса (загружается `go run ./cmd/seed`):

- **«Білім беру саласындағы жасанды интеллект құралдары»** (`ai-tools-in-education`, казахский, 72 часа): программа повышения квалификации для преподавателей, 5 модулей, 10 уроков, 4 теста и итоговый экзамен. Курс начинается сразу с учебного материала; расписание (19.10–02.11.2026, Zoom, аудитория 301) в курс не входит. Темы уроков составлены нами, это не официальная программа.

Сид создаёт модули и уроки только при первой загрузке курса. Чтобы увидеть правки текстов в уже заполненной базе, пересоздайте её.

- Модули открываются по порядку: следующий модуль доступен после всех уроков и теста предыдущего.
- Тест модуля открывается после всех его уроков, итоговый экзамен после всех модулей. Проверка ответов только на сервере, правильные ответы клиенту не отправляются.
- Сертификат выдаётся автоматически, когда пройдены все уроки и сданы все тесты и итоговый экзамен. Один сертификат на запись, повторно не создаётся.
- Код сертификата вида `AIKAU-26-7K3M-9QX2` случайный (40 бит), не подбирается перебором. Страница `/verify/{код}` публичная.
- PDF (A4, альбомный) строится на Go (`backend/internal/certpdf`), шрифты PT Sans и PT Serif поддерживают казахские буквы, Noto Sans KR — корейские (подмножество шрифта, около 2,7 МБ на начертание). QR ведёт на `APP_URL/verify/{код}`.

## Пароль и сессии

Пароль: не меньше 8 символов и хотя бы один специальный символ (не буква, не цифра, не пробел). Правило проверяется и в форме, и на сервере (`backend/internal/auth/password.go`). Пароли хранятся как argon2id. Сессия — случайный токен в cookie `ai_session` (`HttpOnly`, `SameSite=Lax`, `Secure` в production); в базе лежит только его SHA-256. Вход ограничен: 10 неудачных попыток на логин и 200 на IP за 15 минут.
## Языки

Казахский — язык по умолчанию и открывается на `/`, русский, английский и корейский — на `/ru`, `/en` и `/ko`. При первом визите язык выбирается по настройкам браузера. Казахские и корейские переводы (`messages/*.json` и тексты курсов) нужно вычитать носителям языка.

### Тексты курсов на нескольких языках

Оригинал курса лежит в обычных колонках на языке `courses.language`, переводы — в колонках `i18n` (jsonb, ключ — язык) таблиц `courses`, `modules`, `lessons`, `quizzes`, `questions`, `question_options`. API отдаёт перевод по `?lang=`, а если его нет — оригинал; поле `language` в ответе — язык отданного текста, `languages` — все доступные. Для демо-курсов переводы лежат в `backend/cmd/seed/i18n/<slug>.<lang>.json` и сопоставляются с оригиналом по порядку (N-й модуль, N-й урок, N-й вопрос); `go run ./cmd/seed` проверяет форму файла и записывает переводы, в том числе в уже существующие курсы.
