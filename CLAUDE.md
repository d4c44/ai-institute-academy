# AI Institute Academy — project notes

Course platform with verifiable certificates for Korkyt Ata Kyzylorda University. See README.md for setup and the roadmap.

## Architecture
- **Frontend** (repo root): Next.js 16.4 with `cacheComponents` + `partialPrefetching`. Read `node_modules/next/dist/docs/` before using an API you're unsure of; much differs from older Next.
- **Backend** (`backend/`): Go, stdlib `net/http` ServeMux (method patterns), pgx, goose. No ORM, no web framework. Queries are plain SQL in `internal/store`.
- **Database**: PostgreSQL 18 server. Schema lives only in `backend/migrations/*.sql` (uuidv7 keys, snake_case). Rules the type system can't express are CHECK constraints in the migration.
- The Next.js server calls the Go API with `API_URL`; the browser reaches it through the `/api/v1/*` rewrite in `next.config.ts` (same origin, no CORS). Auth sessions (step 3) will be cookies issued by Go.

## Conventions
- **Frontend data reads:** functions in `src/lib/api/` use `"use cache"` + `cacheLife` + `cacheTag`. Components that call them do `await connection()` first and sit inside `<Suspense>`, so `next build` never needs the API. Mutations call `revalidateTag(...)` for the tags they affect (`catalog` for published course data).
- **i18n:** next-intl with `[locale]` as the root param, read via `next/root-params`. Root params don't work in Server Actions or Route Handlers, so pass `locale` explicitly there: `getTranslations({ locale, namespace })`. Use `Link`/`redirect`/`useRouter` from `@/i18n/navigation`. Locales are kk, ru, en, ko (`routing.ts`): add keys to all four `messages/*.json`; `en.json` drives the types. UI strings and known track names are translated in messages; course content is translated in the database (next bullet). Korean needs `word-break: keep-all` (globals.css) and Noto Sans KR as a fallback in `--font-sans`.
- **Course translations:** the original text stays in the normal columns, in `courses.language`; translations live in `i18n jsonb` columns (`{"ru": {"title": ...}}`) on courses, modules, lessons, quizzes, questions and question_options, read with the SQL helpers `i18n_text` / `i18n_texts` / `i18n_lang` (migration 00002), which fall back to the original. The API takes `?lang=` (a `withLang` middleware puts it on the request context; `store.WithLang`/`langOf`), and every response says which language it actually served (`language`) and which exist (`languages`). Frontend: catalog functions take `locale` as an argument (it is part of the `use cache` key); authed reads add `lang` themselves (`withLang` in `lib/api/auth.ts`); the browser quiz submit passes `?lang=`. Translations of the seed courses are `backend/cmd/seed/i18n/<slug>.<lang>.json`, matched to the original **by position** and validated against it (`translations.go`); a new module, lesson, question or option in `main.go` therefore needs the same entry in every translation file. Kazakh and Korean texts are machine-written and need a native speaker's review. A certificate's course title is stored in the student's locale at issue time and re-localised on read (`LocalizedCertificateTitle`).
- **Style:** Coursera-like layout in blue and white: flat, white, hairline borders, one blue (`--primary` #0028B3, hover `--primary-hover` #001178, focus ring #1883FF; the palette is #001178 · #0028B3 · #1883FF · #75C3FF · #C5DBFF, text and neutrals are blue-tinted greys defined in globals.css). Red is kept only for error states (`--destructive`), Source Sans 3. No gradients, glows, blur, decorative illustrations or emoji. Buttons are `h-10`/`h-12` with `rounded-md`. There is no dark theme: `dark:` utilities only apply under a `.dark` class (`@custom-variant` in globals.css); keep that line.
- **Auth:** accounts live in Go. Sign-up takes full name (≥2 words), login (3–32 chars, `[A-Za-z0-9._-]`), year of study 1–6, optional email, password (≥8 chars and ≥1 non-letter/digit/space character; rule in `backend/internal/auth/password.go`, mirrored in `src/lib/api/browser.ts`). Passwords are argon2id; sessions are random tokens in an HttpOnly `ai_session` cookie, only their SHA-256 is stored. Server components read the user with `getCurrentUser()` (`src/lib/api/auth.ts`, forwards the cookie, never cached) inside `<Suspense>`; client forms call `apiSend()` (`src/lib/api/browser.ts`). Failed-login limits: 10 per login and 200 per IP per 15 min, in memory.
- **Learning flow:** progress is derived, never stored: `CourseProgress` in `backend/internal/store/learning.go` computes locks, availability, percent and the next unit from `lesson_progress` and `quiz_attempts`. Every lesson/quiz endpoint re-checks enrollment and unlock server-side; quiz answers are graded in Go and `is_correct` is never sent to the browser. `IssueCertificateIfEligible` runs after each completed lesson and passed quiz; it locks the enrollment row, so a student gets at most one certificate (a revoked one is not silently re-issued). Certificate PDFs are rendered in Go (`internal/certpdf`); the HTML preview (`components/certificate/document.tsx`) mirrors it, keep them in sync.
- **Client hooks that read the URL** (`usePathname`, `useSearchParams`) must sit inside `<Suspense>`, or routes with dynamic segments fail to prerender.
- **Brand:** the product is "AI Institute Academy" (`Brand.name` in messages); "AI Institute" alone is the institute itself (certificate director line). The logo is `public/brand/logo.png`, a royal-blue (#0028B3) on-transparent recolour of the original in `public/brand/source/`. It appears once in the header and on the certificate; do not add it to more places. Don't re-tint it with CSS, regenerate the PNG instead.
- **shadcn/ui** is the `base-nova` preset = Base UI primitives (use `render={<Button />}`, not `asChild`). `cn` comes from the `cn` package. Links styled as buttons: `cn(buttonVariants({ ... }), "extra")`, never `className` inside `buttonVariants`.
- **Go:** handlers return data through `Server.respond`; public catalog responses carry `Cache-Control`. `ORDER BY` fragments come from a whitelist, never from input. Certificates are never deleted: revoke or supersede. Courses with enrollments are archived, not deleted.

## Local environment
- Windows dev machine, no Docker. PostgreSQL 18 runs as a service on :5432; the app role and database are created by `backend/db/init.sql`. Go is on the machine PATH (new shells), binaries go to `backend/bin/` (git-ignored).
- Production image binds `HOSTNAME=0.0.0.0`. A specific IP makes the `/` → `/kk` locale rewrite loop.
